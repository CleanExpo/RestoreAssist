# RestoreAssist

Next.js 15 App Router · TypeScript · Prisma — Australian water-damage restoration platform.

## Repository layout

```
app/              Routes & API (App Router)
components/       UI
lib/              Domain & server logic
hooks/            Client hooks
types/            Shared types
prisma/           Schema & migrations (deploy SSOT)
public/           Static assets
data/content/     Runtime help & training (@/content/*)

config/           ESLint, Vitest, Playwright, Lighthouse
scripts/          CI, ops, agent evals
e2e/              Playwright (incl. browser specs)
tests/            Vitest stubs & unit helpers
docs/             Specs, ADRs, ops archives, project notes

mobile/           Expo + Play Store metadata (fastlane)
ios/ android/     Capacitor native shells
packages/         Workspace packages (pilot-tester)
tools/            Remotion & local video output
docker/           Container context
```

Agent tooling (BMAD, skills, rules) lives under **`.claude/`** — not part of the runtime app.

## Root files (minimal on purpose)

| File | Purpose |
|------|---------|
| `README.md` | This map |
| `AGENTS.md` | Next.js agent rules (may be regenerated by `next dev`) |
| `CLAUDE.md` | Engineering rules for AI sessions |
| `spec.md` | Canonical product spec (CI `check:spec-docs`) |
| `package.json`, `next.config.mjs`, `tsconfig.json`, … | Standard Next.js / Node |

Project backlog, changelog, review rubric: **`docs/project/`**. New product intents: **`docs/intent/`**.

Env template: **`.env.example`**.

## Commands

```bash
npm ci && npm run dev
npm run type-check && npm run lint && npm run test:unit && npm run build
```
