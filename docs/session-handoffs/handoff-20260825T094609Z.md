## 6. UNI-2619, and the three questions it answered

`generate-report-ai.ts:199` built the WHS citation with `.split(" ").pop()`, which returns the
**last** token — in all 8 jurisdictions the bracketed state code, never the year. Every state lost
its year; **Victoria was rendered under a "Work Health and Safety Act" it never adopted** (it runs
the Occupational Health and Safety Act 2004).

- **NZ has the same defect, worse in kind.** `getStateInfo` has no NZ entry, so `stateInfo` is
  `null` and the `else` branch at `:206-212` asserts a **Queensland Development Code** and an
  Australian Act for a New Zealand property. **Not fixed** — needs NZ entries in `getStateInfo`,
  a data-model change. Worth its own ticket.
- **The defect was latent, not live.** `route.ts:477` short-circuits `basic`/`enhanced` to
  `buildStructuredBasicReport` and returns unconditionally, so the broken builder was unreachable.
- **Zero reports shipped wrong.** 17 reports in production, **0 Victorian**, 0 containing the
  mangled string, 4 containing a correct year-bearing citation (positive control). No client
  notification warranted.

Cursor Bugbot then caught that my first fix was a **partial sweep** — I replaced the standards
block and left five `CRITICAL INSTRUCTIONS` lines still ordering the model to cite
`"Work Health and Safety Act 2011"` and `"QDC 4.5"` by name. Fixed, plus a guard asserting on the
**whole** prompt so the next partial sweep fails in CI rather than in review.
