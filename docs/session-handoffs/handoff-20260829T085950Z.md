## 3. Decisions locked + what shipped

**Seven defects. The pattern matters more than the list: every one required leaving the mock behind.**

*In `linear-query.ts`, found by auditing against `@linear/sdk` v92 and the live RA workspace:*

1. **Empty env var silently matched no team.** `.env.example` ships `LINEAR_RA_TEAM_ID=""`; `??` accepts an empty string, so a verbatim `.env` sent `team.key.eq = ""` — zero issues, "No matching issues.", **exit 0**. A false negative in a tool whose only job is reporting open work.
2. **Duplicate issues listed as actionable.** `WorkflowStateFilter.type` documents seven state types; the filter excluded two. The RA team has a live **Duplicate** status (`aec545a9-ad2d-4179-a058-b280b414458d`).

*In `linear-query.ps1`, found by running it under PowerShell 7.4.6:*

3. **An invalid query fabricated an issue and exited 0.** Linear returns GraphQL errors inside a `200`, so `Invoke-RestMethod` does not throw; `$response.data.issues.nodes` was `$null`, and `$null | ForEach-Object` iterates **once**, emitting `: [None]  - `. A triage tool inventing a ticket.
4. **`orderBy: priority` is not a valid `PaginationOrderBy` value** — only `createdAt`/`updatedAt` exist — so ordering never worked.
5. **A missing `LINEAR_API_KEY` sent an empty `Authorization` header** rather than failing.
6. **`duplicate` not excluded** — same as defect 2.
7. **Titles and labels reached the terminal unsanitised.** An ANSI erase-line + cursor-home payload repaints the row, so the listing misreports which issue is urgent. Reproduced, then fixed in both scripts.

**Three corrections I made to my own claims.** Each was stated confidently and was wrong:

- **"Quality Checks did not fire on #2079."** Drawn from one `get_check_runs` snapshot taken before any run existed. The workflow was never misconfigured; the PR was `mergeable_state: dirty` against the wrong base, and GitHub cannot build a merge ref for a conflicted PR, so no run was created. Corrected in commit `7ee316f1`.
- **"I can run the script against real Linear without needing an API key."** False — the script reads `LINEAR_API_KEY`; the MCP connector is a separate credential.
- **"The `.ps1` swallows errors."** Understated. It fabricates a phantom issue row and reports success.

**Decision: PR base is `main`, not `sandbox`.** `.claude/agents/pr-creator.md:24` defaults to `--base sandbox`, which assumes you branched off sandbox. #2079 did not, and following that default produced a **3,974-file, 1,873-commit-divergent, conflicted** PR that also silenced CI.
