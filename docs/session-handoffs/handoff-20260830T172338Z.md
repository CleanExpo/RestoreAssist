## 3. Decisions locked + what shipped

**A masked signal must be unmasked without being excused.** #2103 lets a stale deploy warn rather than abort. #2104 goes further and is the load-bearing decision: when the migration probe fails, the flows now run **and the run still exits 1 regardless**. The tempting fix — make the probe non-fatal — would report green while production's database path is failing, which is the same defect with its sign flipped. The rule lives in `finalSmokeExitCode()` so it is unit-testable: *degraded implies non-zero, always*.

**An expired attestation is not an agent's to refresh.** Release Gate is fail-closed (`--strict`, score < 100 → exit 1) and five owner-evidence files are 56-94 days past the 14-day limit, with `C2-secrets-scan` recorded as an outright `fail`. Editing a `verified:` date or flipping `deferred` to `pass` would forge the human attestation the gate exists to collect. Not done, and no agent should.

**A correction, recorded because hiding it would cost the next session real time.** On seeing four auth-gate tests fail alongside the 504, this session reasoned "one fault, three symptoms — the database path" and said so before reading the assertion text. **That was wrong.** The assertions, once retrieved:

```
Expected: ""
Received: "?callbackUrl=%2Fdashboard%2Ftelemetry"
> 183 |   expect(parsed.search).toBe("");
```

Origin matched. Pathname matched. The redirect to `/login` **works**; NextAuth appends `callbackUrl`, which is its default and correct behaviour, and `assertExactSmokeLocation` demands a bare URL. A tidy causal story was built from test *names* and it pointed the wrong way — in the direction that makes an incident look worse than it is.
