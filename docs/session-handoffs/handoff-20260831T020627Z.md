Then the more important finding. With every producer in place, **the pipeline still could not earn a single point**:

- The scorer was never given `RELEASE_RECEIPT_PUBLIC_KEYS`, so `trustedKeysFromEnv()` returned an empty map and every owner-evidence criterion failed with "no trusted receipt keys configured" — 35 points, unconditionally.

Each new receipt invalidated every receipt already committed, so the subsystem could never hold more than zero valid receipts at once.

Both are fixed (#2126). Separately, the DigitalOcean build-failure flood was diagnosed, and `.claude/WORKFLOWS.md` was found to be telling every agent something false about how production ships.

## 3. Decisions locked + what shipped

**The App Platform health check is a readiness probe, not a drift watchdog** (#2114, #2115). It pointed at `/api/health/migrations`, which answers "is the ledger in the expected state?" — a container can serve traffic perfectly while drift exists, and that endpoint returns 503 on drift and 504 when slow. It also deadlocked: while drift existed, the deploy that would fix it could never go green. Live confirmation arrived later from the smoke log — production's `/api/health/migrations` returns **504** while `/api/health` returns **200**.

Three guards were *enforcing* the broken config, and CodeRabbit found two more after #2114 merged. One was a blocker: `validate_release_spec()` exact-matched a single-key health object, so **the deploy path would have rejected the very spec the renderer produces** — and because it was an equality check, it also required the timings to be absent, mandating the misconfiguration.

**Producers measure the criterion, not its description.** Twice the stated criterion named the wrong thing:

- **F1** said "Vercel Observability alert rules". Production is DigitalOcean; the only Vercel project linked to this repo is `restoreassist-sandbox`, whose domains are `*.vercel.app`. Three alert rules there would have satisfied the wording while watching preview deployments.
- **D1** said "Stripe **and Apple IAP**". There is no Apple IAP — RA-1842 Path B, locked after App Review rejected build 1.0(3). It measures the iOS **block** instead.

**An instrument must prove it can see.** C2's producer plants a canary in a `.md` inside the export and rescans. That control **failed on its first real run** — the first canary was a bare AWS example key, which no gitleaks rule matches.

**Bind evidence to source, not to commits** (#2126). A receipt attests to the source, and recording that attestation is not a change to the thing attested. `sourceTreeDigest()` excludes `docs/evidence/release-gate/`.

**`.claude/WORKFLOWS.md` was lying to every agent** (#2122). It said production "auto-deploys from `main` branch" — the opposite of the truth, in the one file Claude Code auto-loads into every session.

**One owner for the Stripe API version** (#2123). Four clients, not two; one pinned three versions behind.

`/done` shipped (#2124) — the three-layer Definition of Done, gate parity, and a hard stop at the owner gates.
