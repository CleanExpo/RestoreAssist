**Two CI gates caught mistakes this session; both are worth knowing about.**

1. **`check:standards` failed the reconciliation document** because §8 — the section arguing against fabricated citations — quoted a fabricated `S500:2025` citation verbatim as a negative example. Rephrased rather than suppressed with `standards-cite-ignore`; the incident is recorded inside that section.
2. **`gitleaks` failed the BMAD install.** `_bmad/_config/files-manifest.csv` row 48 places the word "key" (from `key-screens.md`) next to a SHA-256 digest, which reads as a `generic-api-key`. Fixed by not committing an installer-generated file rather than by adding a path exemption — `.gitleaks.toml` carries its own warning about what a broad exemption cost last time.

**A trap for the next session:** `gitleaks --no-git` **does not respect `.gitignore`**. After gitignoring the manifest the local scan still reported 1 leak, because the file was still on disk. Verify against `git checkout-index` output, which is what CI actually scans.
